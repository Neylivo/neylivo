# Плагины Ponoi

Плагин — это один файл `.ponoi` (обычный JavaScript). Его можно поставить у себя
(Настройки → Плагины → «Установить из файла») и отправить другу прямо в чат: файл
покажется карточкой с названием, автором и списком разрешений и кнопкой «Установить».

## Как это устроено с точки зрения безопасности

Код плагина выполняется в **Web Worker'е** — отдельной области без доступа к
странице. Это значит, что плагин физически не может:

- прочитать твою сессию (она в `localStorage`, воркеру он недоступен) или куки;
- залезть в DOM и подделать интерфейс — например, нарисовать фальшивое окно входа;
- открыть файл на компьютере или запустить программу;
- сходить в сеть куда попало (только на домены, объявленные в `@hosts`);
- подгрузить посторонний код мимо файла, который человек видел перед установкой.

Это не проверки, которые можно обойти хитрым кодом, — это ограничения браузера.
Всё, что плагину доступно, он получает через объект `ponoi`, и каждый вызов
сверяется с тем, что заявлено в `@permissions`.

Оставшийся риск честно называется: плагин **может** делать то, на что ты согласился
при установке. Если он попросил «отправлять сообщения от твоего имени» — он сможет.
Читай список разрешений.

## Формат файла

```js
/**
 * @name Ночной режим
 * @id nightmode
 * @version 1.0.0
 * @author твой-ник
 * @description Подсвечивает сообщения и добавляет команду
 * @permissions ui, css, commands, messages.write
 * @hosts api.example.com
 */

function onLoad(ponoi) {
  ponoi.css('.msg { border-left: 2px solid hotpink }')

  ponoi.ui.addComposerButton({
    key: 'wave', icon: 'flame', tooltip: 'Помахать',
    onClick: () => ponoi.messages.send('о/'),
  })

  ponoi.commands.register('привет', 'Поздороваться', args =>
    ponoi.messages.send('Привет, ' + (args || 'мир') + '!'))
}
```

`@id` обязателен и уникален — по нему плагин обновляется. `@hosts` нужен только
вместе с разрешением `net`.

## Разрешения

| Разрешение | Что даёт |
|---|---|
| `ui` | Свои кнопки в поле ввода и пункты меню сообщения |
| `css` | Свои стили |
| `commands` | Свои команды в чате (имя может быть на любом языке: `/привет`) |
| `messages.read` | Видеть сообщения в открытом канале |
| `messages.write` | Отправлять сообщения от твоего имени |
| `storage` | Своё хранилище на этом устройстве |
| `net` | Запросы к сайтам из `@hosts` (только https, GET и POST) |
| `settings` | Своя страница настроек |
| `notify` | Всплывающие уведомления |

`ui.addMessageAction` требует ещё и `messages.read` — обработчик получает текст
сообщения, и это должно быть видно в списке разрешений честно.

## Что умеет объект `ponoi`

```js
ponoi.css(текст)

ponoi.ui.addComposerButton({ key, icon, tooltip, onClick })
ponoi.ui.addMessageAction({ key, icon, label, onClick })   // onClick({id, author, content})
ponoi.ui.addSettingsPage({ title, rows: [
  { type: 'toggle', key, label, description, value },
  { type: 'text',   key, label, value, placeholder },
  { type: 'select', key, label, value, options: [{ value, label }] },
  { type: 'button', key, label, onClick },
]})

ponoi.commands.register(имя, описание, обработчик)   // обработчик(строка-аргументов)
ponoi.messages.send(текст)
ponoi.storage.get(ключ) / .set(ключ, значение) / .remove(ключ)
ponoi.net.fetch(url, { method, headers, body })      // -> { ok, status, body }
ponoi.notify(текст)
ponoi.log(...)                                        // в консоль разработчика
ponoi.on('message', m => ...)                         // новое сообщение в открытом канале
ponoi.on('settings', s => ...)                        // человек изменил настройку плагина
```

Все методы асинхронные — возвращают промис. Если разрешения нет, промис
отклоняется с понятным текстом, который можно поймать через `try/catch`.

Доступные значения `icon`: `zap`, `star`, `flame`, `paw`, `cube`, `ball`, `skull`,
`sword`, `rifle`, `car`, `compass`, `flag`, `tag`, `pin`, `link`, `code`, `list`,
`search`, `image`, `camera`, `film`, `music`, `volume`, `bell`, `mail`, `lock`,
`shield`, `crown`, `gamepad`, `message`, `smile`, `paperclip`, `clock`, `folder`,
`copy`, `edit`, `trash`, `rotate`.

## О чём стоит помнить

- **Хранилище общее на плагин, а не на обработчик.** Два события, пришедшие почти
  одновременно, могут оба прочитать старое значение и записать одно и то же —
  обычная гонка, как в любом асинхронном коде. Если считаешь что-то по событиям,
  держи счётчик в переменной модуля, а в `storage` сбрасывай пореже.
- **Плагин ставится на устройство, а не на аккаунт.** На телефоне и на компьютере
  наборы плагинов независимы.
- **Загрузка не должна виснуть.** Если `onLoad` не завершится за 5 секунд, плагин
  считается зациклившимся и не запускается. Долгую работу начинай, но не жди её
  в `onLoad`.
- **Обработчик отвечает за 10 секунд.** Дальше вызов отклоняется.
- Размер файла — до 512 КБ, суммарно все плагины — до 2 МБ.

## Ограничения текущей версии

- Плагин не может рисовать произвольную разметку — только заявлять кнопки, пункты
  меню и строки настроек, которые рисует само приложение. Это осознанно: так
  плагин не может подделать элемент интерфейса.
- Изменять текст сообщения на лету (перевод, шифрование) пока нельзя — событие
  `message` только уведомляет.
