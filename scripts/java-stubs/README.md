# Заглушки Android — чтобы Java хотя бы компилировалась

**Зачем.** Весь нативный код проекта (`android/app/src/main/java/com/ponoi/app/*.java`)
до v1.444.0 **ни разу не компилировался**: на машине нет Android SDK, а `java`
восьмой версии не годится ни для какого современного Gradle. Ошибку в нём было
видно только после сборки APK на чужой машине — то есть никогда.

**Что это даёт.** `npm run test:java` собирает настоящие файлы проекта против
заглушек тех классов Android и Capacitor, которые они трогают. Ловятся: опечатки,
несуществующие методы, неверное число доводов, забытый import, недостижимый код,
несовпадение типов — то есть весь класс ошибок «не собралось».

**Чего это НЕ даёт, и врать тут нельзя.** Заглушки написаны мной по документации,
а не взяты из настоящего `android.jar`. Если я ошибся в сигнатуре, компилятор
согласится с моей ошибкой. Поэтому:

- сигнатуры в заглушках держать **точно как в документации Android**, включая
  версию API, с которой метод существует;
- проверку версии (`Build.VERSION.SDK_INT >= …`) заглушка не проверяет вовсе —
  за неё отвечает чтение кода;
- поведение не проверяется совсем: заглушки ничего не делают.

**Известное расхождение.** `javac` из JDK 25 ругается на `new URL(String)` в
`ApkInstaller.java` как на устаревший. Это разница самого JDK, а не Android: в
Android этот конструктор не помечен устаревшим. Предупреждение оставлено как
есть — «чинить» его под настольную Java значит портить настоящий код.

Настоящая сборка APK по-прежнему происходит только в GitHub Actions.
